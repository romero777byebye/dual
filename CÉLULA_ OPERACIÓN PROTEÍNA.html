RESUMEN DE LA RUTA SECRETORA

ADN (núcleo) → transcripción → ARN mensajero → ribosoma asociado al RER → traducción de la cadena polipeptídica → interior del retículo endoplasmático rugoso (plegamiento y control de calidad) → vesícula de transporte → aparato de Golgi (modificación, clasificación y empaquetado) → vesícula secretora → membrana plasmática → exocitosis.

Recuerda: esta es la ruta de una proteína destinada a la secreción; no todas las proteínas celulares siguen este recorrido.

Proyecto académico

CRÉDITOS

CÉLULA: OPERACIÓN PROTEÍNA es un videojuego educativo de biología celular desarrollado para la Feria de la Ciencia y la Tecnología. Enseña, mediante la juego, la ruta de una proteína destinada a la secreción.

Tecnologías: HTML5 · JavaScript nativo · Canvas 2D · Tailwind CSS (CDN) · MediaPipe Face Landmarker (seguimiento facial en el navegador) · DeviceOrientation (giroscopio en móviles) · Web Audio API (sonido sintetizado) · Firebase Authentication (Google) · Cloud Firestore (ranking).

Privacidad: la cámara se procesa únicamente en el equipo del jugador; no se graba, almacena ni transmite. El ranking guarda solo nombre público, puntuación y datos de la partida.

Aviso científico: los obstáculos, puertas y minijuegos son simplificaciones lúdicas de procesos celulares reales, indicadas como tales dentro del juego.
